# Portofolio M. Reno Hidayat, S.Kom.

> **Live Website**: [renohidayat.web.app](https://renohidayat.web.app)

Portofolio resmi **M. Reno Hidayat, S.Kom.** — Full Stack Software Engineer & Lulusan Informatika Universitas Sebelas April. Menampilkan pengalaman profesional, proyek unggulan (Web, Mobile Flutter, Backend, AI/Machine Learning), riset ilmiah (ResearchGate), serta sertifikasi internasional (IBM SkillsBuild, ASEAN Foundation, Google Cloud, Kominfo).

---

## 🚀 Fitur Unggulan

- **Desain Interaktif & Sinematik**: Animasi halus bertenaga **Framer Motion**, **GSAP**, dan **Lenis Smooth Scroll**.
- **Unified Certificate Modal**: Tampilan interaktif untuk melihat sertifikat resmi (IBM SkillsBuild, ASEAN Foundation, Google Cloud, Kominfo) dengan filter kategori tab, navigasi cepat, dan verifikasi Credly.
- **Dukungan Dua Bahasa (Bilingual)**: Bahasa Indonesia dan English secara dinamis tanpa reload halaman.
- **Full Stack & Real-Time Showcase**: Menampilkan ekosistem ujian digital kampus (SIPENA), katalog UMKM digital (Dapoer Sari Pohaci), riset analisis sentimen ijazah, dan riset ilmiah keamanan informasi berbasis PLS-SEM.
- **Search Engine Optimization (SEO & Image SEO)**:
  - Structured Data Schema.org (`WebSite`, `Person`, `ImageObject`)
  - Google Image Sitemap resmi (`xmlns:image`)
  - Dynamic page-level titles, meta descriptions, and canonical URLs
  - Open Graph & Twitter Cards

---

## 🛠️ Tech Stack

- **Frontend Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: Framer Motion, GSAP (TweenMax), Lottie
- **Icons**: React Icons (Si, Fi, Ai, Bs, Bi)
- **Deployment & Hosting**: Firebase Hosting

## 💻 Menjalankan di Lokal

### Prasyarat
- Node.js 18+ atau 20+
- npm atau pnpm

### Langkah Instalasi
```bash
# Clone repositori
git clone https://github.com/Renohidayat/portofolio-reno.git

# Masuk ke direktori
cd portofolio-reno

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka [http://localhost:5173](http://localhost:5173) di browser Anda.

### Build untuk Produksi
```bash
npm run build
```
