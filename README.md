## Menjalankan di Lokal

### Prasyarat
- Node.js 18+ atau 20+
- npm atau pnpm

### Langkah Instalasi
```bash
# Clone repositori
git clone https://github.com/IrfakMaulana/portofolio-v2.git

# Masuk ke direktori
cd portofolio-v2

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka [http://localhost:9001](http://localhost:9001) di browser Anda.

### Build untuk Produksi
```bash
npm run build
```
